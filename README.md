# Ruben Carrion Portfolio

Portfolio personal de Ruben Carrion, disenador grafico e IA Designer especializado en branding, campanas visuales, retail, contenido con IA y automatizacion creativa.

## Tecnologias

- Next.js 16
- React 19
- Tailwind CSS
- Framer Motion

## Desarrollo local

```bash
npm install
npm run dev
```

## Build de produccion

```bash
npm run build
npm start
```

## SEO

La web incluye metadata para buscadores, Open Graph, Twitter Card, `robots.txt`, `sitemap.xml` y datos estructurados JSON-LD.
